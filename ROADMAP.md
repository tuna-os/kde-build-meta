# KDE Build Metadata Roadmap

> **Repository Status**: Archived / Historical Reference
> **Canonical Active Replacement**: [tuna-os/tromso](https://github.com/tuna-os/tromso)

## Overview

The `kde-build-meta` repository provided BuildStream metadata, elements, and patches for the KDE Plasma desktop stack within the TunaOS ecosystem. All active development, BuildStream definitions, desktop integration elements, and maintenance workflows were consolidated into `tuna-os/tromso`.

## Historical Milestones

- **Pre-consolidation**: Standalone desktop stack definitions modeled on GNOME `gnome-build-meta`.
- **Tromso Consolidation**: Junction points were retired and all build metadata imported into `tuna-os/tromso`.

## Active Planning & Strategy

For ongoing desktop environment planning, Plasma 6 tracking, and build pipeline enhancements, please refer to the active roadmap in [tuna-os/tromso ROADMAP.md](https://github.com/tuna-os/tromso/blob/main/ROADMAP.md).
